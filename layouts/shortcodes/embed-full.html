{{- /* embed-full — a full-bleed, same-origin live embed placed inline in the body (unlike hero-embed, which is lifted out as the page's wide hero). Used for a closing "here's the actual product" beat: the works single template lifts this figure out of the prose column and re-emits it as a direct .use-subgrid child with .place-full, so it spans the full content width (see layouts/works/single.html). Desktop lock: the embedded page is rendered at a fixed DESIGN width (so it always shows its desktop layout, never reflowing to the mobile one) and then scaled to fit the container by assets/js/hero-embed.js. The .video-wrapper is the display window (aspect-ratio + overflow:hidden); the iframe is absolutely positioned at the design size and transform-scaled. See ".embed-lock" in assets/css/style.css. It reuses the hero-embed plumbing: the iframe carries .hero-embed__frame and sits in a .video-wrapper, so the image-blend effect and the theme mirroring reach it, and it is a data-lightbox target of type "embed". The in-page iframe is pointer-events:none so a click reaches the figure and opens the lightbox. Params: src (required) same-origin URL to embed, e.g. "/cadence-start.html" ratio (optional) display aspect-ratio, default "16 / 9" width (optional) design (desktop) width in px, default "1280" title (optional) accessible name for the iframe / lightbox caption (optional) figure caption lightbox (optional) "false" to make it non-clickable, default true */ -}} {{- $src := .Get "src" -}} {{- $ratio := .Get "ratio" | default "16 / 9" -}} {{- $width := .Get "width" | default "1280" | float -}} {{- $title := .Get "title" | default "Interactive embed" -}} {{- $lightbox := ne (.Get "lightbox") "false" -}} {{- if not $src -}} {{- errorf "embed-full: 'src' is required (%s)" .Position -}} {{- end -}} {{- /* design height = width / (ratio) so the iframe frames a `ratio` window of the desktop page */ -}} {{- $rp := split $ratio "/" -}} {{- $rw := float (trim (index $rp 0) " ") -}} {{- $rh := float (trim (index $rp 1) " ") -}} {{- $height := mul $width (div $rh $rw) -}} {{- $wrapStyle := printf "aspect-ratio:%s" $ratio -}} {{- $frameStyle := printf "width:%.0fpx;height:%.0fpx;border:0;display:block" $width $height -}} {{- if $lightbox -}}{{- $frameStyle = printf "%s;pointer-events:none" $frameStyle -}}{{- end -}}

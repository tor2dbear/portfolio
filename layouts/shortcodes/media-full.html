{{- /* media-full — a full-bleed image figure. The works single template lifts a figure with the `media-full` class out of the prose column and re-emits it as a direct .use-subgrid child with .place-full, so it spans the full content width edge to edge (see layouts/works/single.html). Used for a closing "here's the actual product" beat. It mirrors the render-image hook: a responsive (webp + jpg fallback) that participates in the site's image blend (via picture::before/ ::after + img grayscale) and is a data-lightbox image target. The caption is pulled back to a readable measure by ".media-full figcaption" in style.css.
